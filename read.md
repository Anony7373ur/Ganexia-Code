Refleksi dari fungsi HTML, CSS, JAVASCRIPT termasuk GIT

1. GIT
    GIT Adalah sebuah aplikasi open source yang berguna untuk menyimpan repositori ke github agar
    bisa membukanya secara online dan berkolaborasi antar developer untuk kode secara online melalui GITHUB

2. HTML
    HTML atau Hypertext markup languange adalah sebuah bahasa tapi tidak pemrograman yang dimana kodenya untuk
    membuat teks dan pondasi dalam pembuatan website. HTML adalah kode yang digunakan sebelum penggunaan css karena javascript. Tanpa HTML maka css dan javascript tidak akan berguna karena tidak ada teks di dalam website.
    HTML juga dibagi 2 yaitu HTML dan HTML5, tetapi dalam pelajaran ini, saya hanya belajar tentang HTML.

3. CSS
    CSS atau Cascading Style Sheet adalah sekumpulan kode untuk membuat gaya dan keunikan dalam web seperti
    warna, animasi, background, gambar, frame, dan lain lain yang dapat memperindah website kita. CSS harus diiringi oleh HTML agar bisa bekerja karena tidak mungkin hanya frame kosong aja yang ada di web. Fungsi nya sangat bermacam karena banyak bisa dilakukan seperti mengatur margin, padding, pixel, dan lain lain.

4. JavaScript
    Javascript atau JS adalah bahasa programming yang berfungsi untuk membuat suatu fungsi dan kode yang hampir sama dengan koding bahasa pemrograman yang lainnya. Contohnya membuat animasi, Popup, slide, aritmatika, proses data, menyimpan data dan sebagainya. Javascript membuat website kita semakin fungsional dan berguna dalam hal data dan query dalam website.
